# Product Line Profitability and Margin Performance Analysis

## 📊 Project Overview

This project analyzes product-level sales, costs, gross profit, and profit margins for **Nassau Candy Distributor**.

The main objective is to identify how different products and divisions contribute to overall revenue and profitability, while highlighting products with low margins or higher profitability risk.

The project uses **Python, Pandas, Plotly, and Streamlit** to perform data analysis and create an interactive web-based dashboard.

---

## 🎯 Objectives

The project aims to:

- Analyze overall sales and profitability.
- Measure gross profit and gross margin.
- Compare profitability across different divisions.
- Identify high-performing and low-performing products.
- Analyze the relationship between sales, cost, and profit.
- Identify products with potentially low profit margins.
- Understand profit concentration using Pareto analysis.
- Provide interactive filters for exploring the dataset.
- Present business-oriented insights through an interactive Streamlit dashboard.

---

## 🛠️ Technologies Used

- **Python**

- **Plotly** – Interactive visualizations
